# Pandas Academy — интерактивный учебник от нуля до профессионального уровня

**Полный курс:** 8 модулей, 31 учебный ноутбук плюс навигатор (`.ipynb`), 155 самостоятельных заданий с автопроверкой обычного кода.

Учебник рассчитан на разработчика, который знает основы Python. Повторения Python и установки JupyterLab нет: **всё делается в VS Code**. Интернет не нужен для теории, решения задач, тестов и работы с подготовленными данными. Внешние ссылки приведены только для дальнейшего углубления.

## Настройка в VS Code

1. Установите Python 3.11+ и расширения VS Code **Python** и **Jupyter** (сам JupyterLab устанавливать не нужно).
2. Через **File → Open Folder** откройте папку `pandas_academy` целиком.
3. Откройте терминал **в корне этой папки**.

### Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

4. Откройте `00_course_navigator.ipynb` для навигации или сразу `module_01/01_series_and_dataframes.ipynb` и выберите ядро `.venv` через **Select Kernel** в правом верхнем углу.
5. Выполняйте уроки по порядку. Прежде чем открыть практическую часть, прочтите всю теорию и запустите примеры.
6. В каждом задании запустите ячейку с исходными данными. Все переменные уже созданы: например, `df`, `records`, `column`.
7. В следующей ячейке **пишите обычный код, без функции**. Сохраните итог в переменной `result`, заменив `result = None`. Под ячейкой находится статический **ожидаемый вывод**. Следующая ячейка вызывает `check_result(...)` и сообщает, совпадает ли результат.
8. В конце урока запускайте `show_progress()`. Результат автоматически сохраняется в `output/progress.json` и переживает перезапуск VS Code.

## Как устроен курс

- `module_01/...module_08/` — все учебные тетради, включая три итоговых проекта.
- `tests/notebook_checks.py` — автопроверка ячеек и сохранение прогресса.
- `tests/advanced_checks.py`, `tests/fixtures.py` — эталоны и тестовые данные, **не открывать до собственного решения**.
- `data/` — исходные учебные CSV, Excel и JSON и расширенные CSV-наборы для трёх итоговых проектов.
- `output/` — прогресс и результаты упражнений (не включены в архив).
- `COURSE_MAP.md` — полный перечень модулей и занятий.

## Особенности автопроверки

- Автопроверка сравнивает `result` с ожидаемым значением **для показанных в задании данных**. Дополнительных скрытых входов в этом формате нет: студенту не нужно писать универсальную функцию.
- Для таблиц и Series проверяются значения, индексы, названия столбцов и порядок. Для некоторых заданий важны типы данных.
- Перед каждым решением запускайте ячейку входных данных заново: она восстанавливает тестовый пример и ожидаемый результат.
- Проверка показывает `✓` или сообщение о несовпадении; прогресс сохраняется в `output/progress.json`.
- Для заданий на чтение и запись файлы уже подготовлены в ячейке входных данных, искать их вручную не нужно.

## Рекомендуемый темп

На каждый урок отводите 2–4 часа, сложные главы и проекты — больше. Теорию не пропускайте, даже если метод кажется знакомым. Нацеливайтесь на способность объяснить, почему выражение работает и когда оно даст неправильный результат, а не на механическое прохождение тестов.

## Примечание к версии pandas

Курс рассчитан на **pandas 3.x**, в котором действует Copy-on-Write, а строковые столбцы могут иметь отдельный строковый dtype. После установки выполните `import pandas as pd; print(pd.__version__)`. Если версии существенно различаются, возможны отличия в поведении и типах.

## Если возникла ошибка `No module named tests`

В исправленной версии первая ячейка каждого ноутбука ищет папку `pandas_academy`
и добавляет её в путь импортов. Она также переключает рабочую папку на корень курса,
поэтому пути `data/` и `output/` работают одинаково в любом модуле.
Откройте в VS Code папку `pandas_academy` целиком (не отдельную папку `module_01`),
выберите ядро Python из `.venv` и запустите первую ячейку.

Если вы обновляете старый архив, скопируйте из нового не только ноутбуки,
но и папку `tests`. Убедитесь, что `tests/notebook_checks.py` существует.


## Откуда берутся исходные данные

В начале каждого задания есть ячейка с готовыми данными. В ней создаются переменные с **простыми именами** (`df`, `records`, `path`, `column` и т. д.).

**Порядок работы**: прочитать условие → запустить данные → написать код и присвоить результат `result` → сравнить с ожидаемым выводом прямо под кодом → запустить автопроверку.

Ни в одном упражнении не нужно писать `def`, вызывать функцию самостоятельно или искать загадочные переменные в папках проекта.
